# Text Analysis

This was a deadend set of tools that were my first attempt at trying to pull text from images and do dialog alerts.  I tried multiple OCR programs, and the end result is that they all performed pretty bad at trying to pull out text from screenshots of a live pokemon game.  

This has been replaced by using game_state in the mGBA lua script to both read when the game says that it's in a dialog window and what those strings are.  While not really human like, it actually works.  

These are mostly just here as historcal at this point to just acknowledge the attempt.
